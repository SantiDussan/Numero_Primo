# Numero_Primo
Repositorio en Python para comprombar si los primeros 100 números corresponden a números primos, realizado con series y parte de if

## Número Primo ¿Qué es?
Es un número que solo se puede dividir entre 1 y el mismo, como lo puede ser el número 2,3,4.

## Uso de Modulo `%` 
Si buscas el operador de residuo o módulo representado con el símbolo `%`, este calcula el sobrante de una división entera, por ejemplo: `7 % 3` da `1`, con eso podremos saber si el número es primo, porque el módulo debe ser igual a 0.
